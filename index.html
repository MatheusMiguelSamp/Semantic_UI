O que é o Semantic UI?

O Semantic UI é um framework front-end open source lançado em 2013 que usa nomes de classes CSS que soam como "linguagem natural" — por exemplo, ui red button em vez de nomes abstratos. Isso torna o HTML mais legível e intuitivo para quem está aprendendo desenvolvimento de interfaces.

Ele inclui um sistema de grid responsivo, mais de 50 componentes de UI, integração nativa com os ícones do Font Awesome, e uma paleta de cores semânticas consistente — que é justamente o que vamos explorar abaixo.
